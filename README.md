# معمل محاكاة الكلاسيك كنترول
### Classic Control Simulation Lab

تطبيق تعليمي لمحاكاة دوائر التحكم الكلاسيكي وتشغيل المحركات: شرح المكونات 3D، توصيل الدوائر ومحاكاتها، دائرة القوى والتحكم بمعايير IEC 60617.

**تطوير: Mohamed _ Eldawly**

## الرفع على GitHub Pages
1. اعمل مشروع (Repository) جديد على GitHub.
2. ارفع كل الملفات دي في الصفحة الرئيسية للمشروع (من غير أي مجلدات).
3. من Settings ← Pages اختار Branch: main و Folder: / (root) واحفظ.
4. بعد دقيقة هيبقى الرابط: `https://اسم_الحساب.github.io/اسم_المشروع/`

## لوحة التحكم
- الإعدادات ← دخول لوحة التحكم.
- كلمة السر الافتراضية موجودة عندك، وغيّرها من لوحة التحكم أول مرة.
- أي تعديل من لوحة التحكم انشره بتنزيل `config.json` ورفعه مكان القديم، أو بالنشر المباشر على GitHub.

## الملفات
| الملف | الوظيفة |
|---|---|
| index.html | التطبيق كامل |
| config.json | إعدادات الأدمن (فتح/قفل الأجزاء، الأكواد، التحديث الإجباري) |
| manifest.webmanifest | تثبيت التطبيق على الموبايل |
| sw.js | التشغيل بدون إنترنت بعد أول فتح |
| icon-*.png | أيقونات التطبيق |
