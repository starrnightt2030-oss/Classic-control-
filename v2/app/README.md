# Control Academy — أكاديمية التحكم الكهربائي
تطبيق Flutter (v2) لـ Windows وAndroid

## اللي فيه دلوقتي
- **الرئيسية:** كمّل من حيث وقفت، واختصارات، وقاعدة السلامة، ودايرة التشغيل المباشر.
- **المكتبة:** 32 مكوّن، بحث بالاسم أو اسم الجزء، وتصنيفات.
- **صفحة المكوّن:**
  - مجسم 3D (دوران، تقريب، تحريك).
  - مُجمّع / مفكوك بحركة.
  - أسماء الأجزاء عربي وإنجليزي بأسهم.
  - لمس الجزء يختاره ويشغّل شرحه الصوتي (لو اتسجّل).
  - شرح الجزء، والعطل الشائع، وطريقة الاختبار.
  - الدروس، والأنواع (variants)، والمراجع.
- **المخططات:** مخطط القوى ومخطط التحكم لدايرة التشغيل المباشر بالرموز الكلاسيك IEC 60617، مع تقريب بالإصبعين أو بالماوس.
- **التخطيط:** شريط تحت على الموبايل الطولي، وشريط جانبي على الويندوز والموبايل العرضي.

## الإصدار 2.1 (ملاحظات التجربة الأولى)
- **المقدمة:** مقدمة متحركة 3D متصممة على Blender (`models/intro.py`): كابلات بتدخل في ترامل الكونتاكتور، وشرارة عند كل توصيلة، والدايرة بتتكهرب. بعدها بيظهر اللوجو والإصدار والمطوّر، ومعاها صوت متركّب (`audio/intro_sound.py`).
- **اللوجو:** لوجو Control Academy بقى أيقونة التطبيق على أندرويد وويندوز.
- **الواجهة بالكروت:**
  - كروت كبيرة بصور توضيحية بتتسحب يمين وشمال، وأي كارت بيفتح بحركة تحوّل (container transform).
  - المكتبة بقت صفوف كروت لكل تصنيف.
- **العارض 3D:**
  - ألوان طبيعية أكتر (ACES، وإضاءة أهدى، وظل تحت المجسم).
  - الفك والتركيب بشريط سحب.
  - أسماء الأجزاء بأرقام وأسهم على كل الشاشات، وزرار بيخفيها ويظهرها.
  - الضغط على اسم الجزء في القايمة بيحدده ويقرّب عليه.
- **ورقة الدرس:** صورة PNG أو PDF منسّقة فيها الشكل الخارجي، والمفكوك بالأرقام، والتعريف، والأجزاء وشرحها وأعطالها واختبارها، والدروس، والمراجع.
- **فيديو لكل مكوّن:** عرض بيتسجّل من العارض نفسه (حوالي 16 ثانية، 1280×720، MP4 أو WebM حسب الجهاز): لفّة، وفك بالأسماء، وتركيب. وبعدها تحفظه أو تبعته.
- **الحفظ:** على ويندوز بتختار مكان الحفظ، وعلى أندرويد بتطلع قايمة المشاركة.

## التشغيل محليًا
```
cd v2/app
python tool/sync_assets.py          # ينسخ الموديلات والمحتوى والصوت من v2/
python tool/make_cards.py           # (اختياري) يعيد صور الكروت من رندرات Blender
flutter create --platforms=android,windows --org com.eldawly --project-name classic_control .
python tool/patch_platforms.py      # صلاحيات أندرويد، الاسم، الأيقونات، عنوان نافذة ويندوز
flutter run -d windows              # أو جهاز أندرويد
```

## البناء الآلي
`.github/workflows/v2-app.yml`: أي push على `v2-rebuild` بيبني:
- APK للأندرويد.
- ZIP للويندوز.

وبينزّلهم في **Releases** كنسخة تجريبية.

## البنية
| المسار | الدور |
|---|---|
| `lib/data/` | موديلات المحتوى (`models.dart`)، والتصنيفات وأسماء الأنواع (`catalog.dart`)، وتحميل المحتوى والتقدّم (`repository.dart`) |
| `lib/services/asset_server.dart` | سيرفر محلي 127.0.0.1 بيقدّم ملفات التطبيق للـ WebView |
| `lib/services/audio_service.dart` | الشرح الصوتي والمؤثرات |
| `lib/ui/viewer3d.dart` + `assets/web/viewer.js` | عارض three.js والجسر مع Dart |
| `assets/diagrams/*.svg` | المخططات (متولّدة من `v2/design/gen_schematic.py`) |
| `tool/` | المزامنة، وتعديل المنصات، وأيقونة التطبيق، وتقارير CI |

## إضافة الصوت
1. حط ملفات mp3 في `v2/assets/audio/<component>/` بنفس الأسماء الموجودة في ملفات المحتوى.
2. شغّل `sync_assets.py`.
3. الزرار هيشتغل لوحده.

## معمل اللوحة (`lib/lab/`)
- `catalog.dart`: المكونات وصورها وربط أطراف الصورة بأطراف محرك المحاكاة.
- `model.dart`: مستند اللوحة (المكونات والأسلاك بالملّيمتر) والحفظ وترقيم الأسلاك.
- `paint.dart`: رسم اللوحة والقضبان والأسلاك الحرة والجلب، ومسار التيار المتحرك، والشرارة والدخان.
- `lab_page.dart`: الشاشة الكاملة: المكتبة، والسحب، والتوصيل بالسحب من طرف لطرف، والتشغيل، والاحتراق والاستبدال.
- `faults.dart`: مولّد الأعطال وسجلّها. `templates.dart`: ورقة العمل الفاضية، ومثال DOL، وأمثلة القصر والاحتراق للمعاينة.
- `projects.dart`: حفظ وفتح المشاريع بأسماء (للمعمل والمخطط).

## محاكي الدوائر الخطية (`lib/schem/`)
- `symbols.dart`: رموز IEC 60617 على شبكة (20 بكسل للوحدة)، وأطرافها، ورسمها في حالة التعديل والتشغيل.
- `model.dart`: مستند المخطط، وتحويله لمحرك المحاكاة (`toSim`)، وأرقام النقط، وقائمة المكونات، وتوجيه الأسلاك بزوايا قائمة، ومثال DOL.
- `sheet_paint.dart`: رسم الورقة والإطار وجدول العنوان والأسلاك ومسار التيار، وصفحة قائمة المكونات.
- `schem_page.dart`: الشاشة: المكتبة، والرسم، والتوصيل، والمحاكاة، والخصائص.
- `export.dart`: ملف PDF (صفحة الرسم + قائمة المكونات).
- المعاينة في CI: `lib/main_lab_preview.dart?page=schem`.
- الصور: `models/render_panel.py` يرندر من ملفات GLB إلى `assets/panel/`.
