# تطبيق Flutter (v2) — Windows + Android

## اللي فيه دلوقتي
- **الرئيسية:** كمّل من حيث وقفت، واختصارات، وقاعدة السلامة، ودايرة التشغيل المباشر.
- **المكتبة:** 32 مكوّن، بحث بالاسم أو اسم الجزء، وتصنيفات.
- **صفحة المكوّن:**
  - مجسم 3D (دوران، تقريب، تحريك).
  - مُجمّع / مفكوك بحركة.
  - أسماء الأجزاء عربي وإنجليزي بأسهم.
  - لمس الجزء يختاره ويشغّل شرحه الصوتي (لو اتسجّل).
  - شرح الجزء، والعطل الشائع، وطريقة الاختبار.
  - الدروس، والأنواع (variants)، والمراجع.
- **المخططات:** مخطط القوى ومخطط التحكم لدايرة التشغيل المباشر بالرموز الكلاسيك IEC 60617، مع تقريب بالإصبعين أو بالماوس.
- **التخطيط:** شريط تحت على الموبايل الطولي، وشريط جانبي على الويندوز والموبايل العرضي.

## التشغيل محليًا
```
cd v2/app
python tool/sync_assets.py          # ينسخ الموديلات والمحتوى والصوت من v2/
flutter create --platforms=android,windows --org com.eldawly --project-name classic_control .
python tool/patch_platforms.py      # صلاحيات أندرويد، الاسم، الأيقونات، عنوان نافذة ويندوز
flutter run -d windows              # أو جهاز أندرويد
```

## البناء الآلي
`.github/workflows/v2-app.yml`: أي push على `v2-rebuild` بيبني:
- APK للأندرويد.
- ZIP للويندوز.

وبينزّلهم في **Releases** كنسخة تجريبية.

## البنية
| المسار | الدور |
|---|---|
| `lib/data/` | موديلات المحتوى (`models.dart`)، والتصنيفات وأسماء الأنواع (`catalog.dart`)، وتحميل المحتوى والتقدّم (`repository.dart`) |
| `lib/services/asset_server.dart` | سيرفر محلي 127.0.0.1 بيقدّم ملفات التطبيق للـ WebView |
| `lib/services/audio_service.dart` | الشرح الصوتي والمؤثرات |
| `lib/ui/viewer3d.dart` + `assets/web/viewer.js` | عارض three.js والجسر مع Dart |
| `assets/diagrams/*.svg` | المخططات (متولّدة من `v2/design/gen_schematic.py`) |
| `tool/` | المزامنة، وتعديل المنصات، وأيقونة التطبيق، وتقارير CI |

## إضافة الصوت
1. حط ملفات mp3 في `v2/assets/audio/<component>/` بنفس الأسماء الموجودة في ملفات المحتوى.
2. شغّل `sync_assets.py`.
3. الزرار هيشتغل لوحده.
