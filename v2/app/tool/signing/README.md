# توقيع نسخ الاختبار (Android)

`debug.keystore` مفتاح **ثابت لنسخ الاختبار فقط** (alias `androiddebugkey`، كلمة السر `android`).
الـ CI بينسخه لـ `~/.android/debug.keystore` قبل البناء، فكل نسخة بتطلع بنفس التوقيع،
والتحديث بيتثبت فوق النسخة القديمة من غير مسح.

قبل النشر على المتجر: مفتاح إصدار حقيقي في GitHub Secrets، ومش في الريبو.
