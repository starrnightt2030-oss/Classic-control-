# تصميم واجهة التطبيق (v2)

التصميم الحي (Design canvas): https://claude.ai/artifact/JVKt7VkonaunRzFEDXSSsx

## الاتجاه البصري: «جرافيت وإشارة» (Graphite & Signal)
- خلفية غامقة زي جوه الطبلون، والمجسم 3D هو البطل.
- الألوان ليها معنى ثابت (منطق IEC 60073):
  | الدور | اللون |
  |---|---|
  | الخلفية | `#0B0F12` |
  | الكروت | `#131A1F` |
  | الحدود | `#26323C` |
  | النص | `#E8EEF2` / ثانوي `#93A3AF` |
  | فعل + تحذير سلامة (كهرماني) | `#F5A400` |
  | عليه جهد / شغال (سماوي) | `#3FD5E8` |
  | تشغيل (أخضر) | `#3DDC84` |
  | إيقاف وطوارئ (أحمر) | `#FF5A4F` |
- الخطوط: Cairo للنص، JetBrains Mono للأكواد وأرقام الترامل (بشكل جلبة السلك).
- أيقونات خطية 1.75 على شبكة 24 مرسومة من رموز الكنترول (ريل، موديولات، NO/NC، كويل).
- أيقونة التطبيق: 3 اختيارات (سطر المخطط / النقطة المفتوحة / الترمينال).
