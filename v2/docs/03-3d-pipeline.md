# 03 — خط إنتاج النماذج ثلاثية الأبعاد

كل النماذج **متبنية بالكود** (Blender Python عن طريق مكتبة `bpy`)، مش بالرسم اليدوي. وده بيدّي:
- مقاسات حقيقية بالمللي، وستايل واحد لكل المكونات.
- ملكية كاملة للنماذج، من غير رخص خارجية.
- تعديل سهل: تغيّر رقم وتعيد التشغيل.
- كل جزء قطعة منفصلة جاهزة للتفكيك، وأماكن الترامل جاهزة للتوصيل.

## الإحداثيات والوحدات
- الكود بيكتب بالـ **مللي**، والتصدير بالـ **متر** (معيار glTF).
- **X** = العرض، و**Y** = العمق، و**Z** = الارتفاع.
- **وش المكون ناحية −Y**، وظهره (ناحية لوحة التركيب أو الدين ريل) ناحية +Y.
- مكونات الباب (الضواغط واللمبات) استثناء: محورها Z، والراس لفوق (الملف `door_devices.py`، وهيتعاد).

## المكتبات
- **`lib.py`**: الخامات (بلاستيك بملمس، ونحاس، وفضة، وزنك، وكروم...)، والأشكال (`box` و`cyl` و`torus`)، و`text` للطباعة البارزة، و`screw_terminal` (مسمار ووردة وEmpty للتوصيل)، و`studio` للإضاءة والكاميرا، و`render`، و`export` لملف GLB.
- **`kit.py`**: دوال بالمللي (`B` صندوق، و`CYL` أسطوانة على أي محور، و`cbox`/`ccyl` للقطع، و`T` للنص، و`helix` للسوست والملفات، و`screw`)، و`merge` اللي بيجمّع كل مجموعة في قطعة باسمها وبيكتب الـ extras، و`explode` و`anchors` و`project`، و`run` اللي بيبني ويرندر ويصدّر.
- **`callouts.py`**: بيرسم الأسهم والأسماء عربي وإنجليزي على صورة التفكيك، بترتيب تلقائي للملصقات (`auto`).

## إزاي تضيف مكون جديد
1. اعمل ملف `xxx.py` فيه:
   - قاموس `PARTS = { id: (اسم عربي, English name, (dx, dy, dz) explode mm [, anchor (x,y,z) mm]) }`
   - دالة `build(M)` بتضيف الأشكال لمجموعات `kit.G[id]` باستخدام `B` و`CYL` و`T` و`screw`...
2. في الآخر اكتب:
   ```python
   kit.run("xxx", module, cam_assembled_dict, cam_exploded_dict, modes)
   ```
3. ارسم الأسهم: `callouts.auto("xxx", PARTS, "عنوان عربي", "English title")`.
4. **راجع الصور بعينك.** الأخطاء الشائعة: نص مستخبي ورا جزء، وقطع لـ Boolean بيفتح وش خارجي، وقطع متداخلة بعد التفكيك.
5. انقل GLB والصور لـ `assets/`، واكتب `content/xxx.json`، وحدّث `05-progress.md`.

## ملاحظات فنية مهمة
- `lib.reset()` بيمسح المشهد و**كاش الخامات** (`_MATS`)، ولازم يتنادى في أول كل بناء.
- `kit.start()` بيمسح `kit.G` و`TERMS` كمان. ولو استخدمت متغيرات عامة في ملفك، امسحها بنفسك.
- القطع بالـ Boolean نوعه `EXACT`، وبيتطبق قبل الـ Bevel.
- لما تجوّف جسم (shell)، **مدى التجويف لازم يسيب الوشوش الخارجية**. شوف الحل في `mcb.py` (`housing_half`).
- `screw_terminal` بيطبّق موقع الأجزاء قبل ما يلفها. ولو غيّرته، اتأكد إن الرأس طالع بره الوردة.
- خط Cairo فيه الحروف العربي والإنجليزي والأرقام متجمعين (`fonts/Cairo-*.ttf`). وأي خط تاني لازم يكون فيه الاتنين، وإلا هتطلع مربعات.

## قبل الاستخدام في التطبيق (لسه متعملش)
- **تخفيف الملفات:** ملفات GLB دلوقتي من 1 لـ 4 ميجا، بسبب الـ bevel والنصوص. وهنستخدم `gltf-transform` (meshopt أو draco) مع تبسيط للنسخة اللي في المعمل (LOD).
- تقليل عدد الخامات المتكررة (لكل مكون خامات بأسماء مختلفة لنفس اللون).
