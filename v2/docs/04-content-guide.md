# 04 — دليل كتابة الشرح والصوت

## الأسلوب
- **العامية المصرية**، بنفس طريقة المدرب في الورشة، لكن **بمصطلحات علمية دقيقة**: نقول "فيض مغناطيسي" و"فئة الاستخدام AC-3" و"منحنى زمن عكسي".
- **أكاديمي ومرجعي:** الطالب هيذاكر منه، فمفيش معلومة تقريبية من غير ما نقول إنها تقريبية.
- **كل رقم ليه مصدر:** مواصفة قياسية مذكورة في `references`، أو مكتوب عليه في `review_note` إنه مثال للموديل ويتراجع من الكتالوج.
- جمل قصيرة تتقري بصوت عالي بسهولة: نص الجزء الواحد من 20 لـ 35 ثانية.
- **الأمان دايمًا:** أي فحص داخلي يتقال "والكهربا مفصولة".

## شكل ملف المحتوى `content/<component>.json`
```json
{
  "component": "contactor",
  "name_ar": "الكونتاكتور", "name_en": "AC Contactor",
  "model": "contactor.glb",
  "variants": ["..."],                       // اختياري (زي القواطع 1-4 بول)
  "intro":  { "audio": "contactor/intro.mp3", "text_ar": "..." },
  "lesson": [                                // أقسام الدرس الأكاديمي
    { "id": "principle", "title_ar": "نظرية التشغيل", "title_en": "...", "text_ar": "..." }
  ],
  "parts": [                                 // id = اسم القطعة في GLB
    { "id": "coil", "name_ar": "...", "name_en": "...",
      "audio": "contactor/coil.mp3",
      "text_ar": "الشرح الصوتي",
      "fault_ar": "العطل الشائع",
      "test_ar": "طريقة الاختبار",
      "anchor": "اختياري: Empty أو قطعة تانية يتربط بيها السهم" }
  ],
  "references": ["IEC 60947-4-1 ..."],
  "review_note": "ملاحظات للمراجع"
}
```

## الصوت
- كل نص ليه ملف صوت بالمسار المكتوب في `audio`، زي `contactor/coil.mp3`.
- التسجيل بتطبيق **Studio-Eldawly** (تعليق صوتي عربي) أو بصوت مدرب، **بنفس الصوت في التطبيق كله**.
- الصيغة المقترحة: MP3 أو Opus، أحادي، من 48 لـ 64 kbps. حجم المقطع حوالي 100 KB.
- **لسه:** هنطلّع ملف نصوص مرتب للتسجيل (`scripts_for_recording.md`)، كل فقرة مكتوب جنبها اسم الملف. وده هيتعمل لما المحتوى يكمل.

## المراجعة
قبل التسجيل والنشر، **مدرب من مركز التدريب يراجع النصوص** مراجعة فنية أخيرة.
