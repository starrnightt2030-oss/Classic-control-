# أكاديمية التمديدات الكهربية — Electrical Wiring Academy

تطبيق Flutter (Android + Windows) لتعليم التمديدات الكهربية السكنية. تطوير Mohamed Eldawly.

## اللي فيه
- **21 دايرة** (لمبة بمفتاح، بريزة، توالي وتوازي، نجفة، دفياتير، انترميديت 3 و4 أماكن، دايمر، فلورسنت، ماكينة سلم، كالون، جرس، RCD، درايفر LED، عداد ولوحة).
  كل دايرة ليها: توصيل جاهز، دليل خطوة بخطوة بأطراف بتنور، تحدي بتقييم بالنجوم، واكتشاف أعطال بالآفوميتر ومفك الاختبار.
- **محاكي حقيقي**: حل شبكة بالعُقد (Nodal analysis) لكل الدواير، قواطع بتفصل في القصر والحمل الزيادة، مفتاح تسريب بيفصل على 30mA، فيوز رئيسي، فلورسنت ببلاست وستارتر، ماكينة سلم بمؤقت، ودخان وشرار وأصوات.
- **لوحة بعرضين**: لوحة خشب واقعية، أو مخطط خطي IEC (محاكي رسم الدواير) — ونفس الدايرة بالمسقط.
- **المعمل الحر**: مكتبة مكونات، سحب وتوصيل، ألوان أسلاك، حفظ وفتح، عطل عشوائي للمدرب.
- مكتبة العِدد والمكونات، جدول الرموز، طرق الرسم، 9 دروس، 6 حاسبات، مشروعات، شقة تفاعلية، بنك أسئلة وانترفيو وشهادة.
- وضع السبورة التفاعلية (75 بوصة) من الإعدادات.

## التطوير
```
cd wiring/app
flutter pub get
flutter test          # محرك المحاكاة + كل الدواير + أعطالها + الواجهة
flutter run -d windows
```
فولدرات المنصات (android/windows) بتتعمل في CI بـ `flutter create` + `tool/patch_platforms.py`.
الأصوات متولدة بـ `python tool/make_sfx.py`.

## البناء
`.github/workflows/wiring-app.yml` بيبني APK وWindows مع كل push وبينشرهم كنسخة تجريبية `wiring-build-N`.
